*Think first. Code second.*

## What is this?

**Problem First Programming** is an introductory course for anyone with no engineering background who wants to learn how to solve problems using software.

This course treats programming as a **tool**, not a goal. The focus is on understanding problems, designing solutions, and choosing the right technology—before writing any code.

---

## Why “Problem First”?

Modern tools—including AI—can generate code quickly.  
What they cannot replace is **clear thinking**.

The difference between inexperienced and experienced engineers is not syntax knowledge, but the ability to:

- Understand a problem deeply  
- Break it down into smaller parts  
- Choose the right tool  
- Use technology to *support* thinking, not replace it  

This course is designed to build that mindset first.

---

## Who is this for?

This course is for anyone who:

- Has **no prior engineering or programming background**
- Wants to learn how software helps solve real problems
- Is curious about Python, R, and JavaScript
- Wants to understand how AI fits into modern software work
- Prefers thinking and reasoning over memorizing syntax

No prior experience is required.

---

## What you will learn

By the end of the course, you will be able to:

- Approach problems using a structured problem-solving process
- Understand when and how to use programming responsibly
- Use Python to solve logical, mathematical, and automation problems
- Use R to analyze data and interpret results
- Use JavaScript to build interactive web applications
- Publish projects using GitHub
- Build a simple full-stack application

---

## Course Structure

- **Duration:** 10 weeks  
- **Time commitment:** 5 hours per week  
- **Format:** Concept-driven, project-based  

Each topic starts with a problem, followed by discussion, design, and implementation.

---

## Weekly Overview

### Week 1 – Problem Solving Fundamentals
Understanding problems, defining inputs and outputs, and thinking before coding.

### Week 2 – Engineering Thinking & AI
Junior vs senior thinking, tool selection, and responsible use of AI.

### Week 3 – Python I: Logic & Control
Variables, conditionals, loops, and basic problem solving.

### Week 4 – Python II: Structuring Solutions
Functions, modularity, and a Python-based problem-solving project.

### Week 5 – R I: Working with Data
Data, statistics, and visualization as tools for reasoning.

### Week 6 – R II: Interpretation
Cleaning data, drawing conclusions, and communicating results.

### Week 7 – JavaScript I: Interaction
HTML, CSS, JavaScript basics, and user interaction.

### Week 8 – JavaScript II: Web Applications
Building and publishing a small interactive web app.

### Week 9 – Software Development Basics
Version control, debugging, documentation, and architecture.

### Week 10 – Final Project
A small full-stack project using:
- JavaScript (frontend)
- Python (backend with simple web scraping)

---

## Projects

- **Python Project:** Logical or physics-based problem solver  
- **R Project:** Data analysis and interpretation  
- **JavaScript Project:** Interactive web application  
- **Final Project:** Full-stack application published online  

Each project emphasizes problem understanding and tool choice.
