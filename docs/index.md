# Problem First Programming
*Think first. Code second.*


---


## What is this?


**Problem First Programming** is an introductory course for anyone with no engineering background who wants to learn how to solve problems using software.


Programming is treated as a **tool**, not the objective. The focus is on understanding problems, designing solutions, and choosing the right technology *before* writing code.
