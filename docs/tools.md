# Tools & Setup

This course uses a small set of tools chosen for clarity, accessibility, and real-world relevance.

The goal is not to master tools, but to understand **when and why** to use them.

---

## Programming Languages

### Python

Python is used as a general-purpose problem-solving tool.

It is well suited for:
- Logical reasoning
- Mathematical and physics-based problems
- Automation
- Backend services

Python emphasizes readability and clarity over complexity.

---

### R

R is used for problems involving data and uncertainty.

It is well suited for:
- Data analysis
- Statistics
- Visualization
- Interpreting results

R helps focus on meaning and insight, not just computation.

---

### JavaScript

JavaScript is used for problems involving users and interaction.

It is well suited for:
- Web interfaces
- Interactive tools
- Visual feedback
- Simple applications published online

JavaScript allows solutions to be shared and used easily.

---

## Development Tools

### Code Editor

- **Visual Studio Code** is recommended
- Any editor that supports plain text is acceptable

The editor is a workspace, not a requirement.

---

### Version Control

- **Git** is used to track changes
- **GitHub** is used to publish and share work

Version control is introduced as a way to think clearly about progress and decisions.

---

### Web Browser

A modern web browser is required to:
- Test web applications
- Inspect behavior
- Understand how users interact with software

---

## AI Tools

AI tools may be used in this course, but intentionally.

They are useful for:
- Exploring ideas
- Generating examples
- Assisting with implementation

They are not a substitute for:
- Understanding the problem
- Designing a solution
- Making decisions

Clear thinking comes first.

---

## Guiding Principle

> Tools support thinking.  
> They do not replace it.

All tools in this course exist to help express solutions—not to avoid the work of reasoning.
