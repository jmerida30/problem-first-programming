# Weekly Structure

The course is organized into **10 weeks**, with each week focusing on a specific type of problem and the tools used to approach it.

Each week follows the same pattern:
- Understand the problem
- Discuss possible approaches
- Choose appropriate tools
- Implement a solution
- Reflect on the result

---

## Week 1 – Problem Solving Fundamentals

**Focus:** Thinking before coding

- What it means to solve a problem
- Defining inputs, outputs, and constraints
- Breaking problems into smaller parts
- Expressing solutions without code

No programming is required this week.

---

## Week 2 – Engineering Thinking & AI

**Focus:** How experienced practitioners think

- Junior vs senior mindset
- Choosing tools intentionally
- The role of AI in modern problem solving
- When automation helps—and when it hurts

Problems are designed to be solved *with reasoning first*.

---

## Week 3 – Python I: Logic and Control

**Focus:** Using code to express logic

- Variables and data types
- Conditionals and loops
- Translating problem steps into code
- Comparing manual and programmatic solutions

Python is introduced as a general-purpose problem-solving tool.

---

## Week 4 – Python II: Structuring Solutions

**Focus:** Clarity and reuse

- Functions and modular thinking
- Reducing repetition
- Improving processes with automation

**Project:**  
A Python-based problem solver (logical, mathematical, or physics-related).

---

## Week 5 – R I: Working with Data

**Focus:** Problems involving data and uncertainty

- Understanding datasets
- Descriptive statistics
- Visualizing information
- Using data to support reasoning

R is introduced as a tool for analysis and insight.

---

## Week 6 – R II: Interpretation and Decisions

**Focus:** Meaning over numbers

- Cleaning data
- Comparing groups
- Identifying relationships
- Communicating conclusions

**Project:**  
A small data analysis project with written interpretation.

---

## Week 7 – JavaScript I: Interaction

**Focus:** Problems involving users

- How the web works
- HTML and CSS basics
- JavaScript fundamentals
- Responding to user input

JavaScript is introduced as a tool for interaction.

---

## Week 8 – JavaScript II: Web Applications

**Focus:** From logic to interface

- Structuring a small web application
- Managing state and feedback
- Publishing a project online

**Project:**  
An interactive web application published using GitHub Pages.

---

## Week 9 – Software Development Basics

**Focus:** Building software responsibly

- What software development is
- Version control with Git
- Debugging and error handling
- Documentation and project structure

Preparation for the final project.

---

## Week 10 – Final Project

**Focus:** End-to-end problem solving

**Final Project:**  
A small full-stack application with:
- JavaScript frontend
- Python backend
- Simple data collection or web scraping
- Clear problem definition and solution design

The emphasis is on architecture, clarity, and tool choice—not complexity.

---

## Progression

Each week builds on the previous one.

The goal is not speed, but understanding:
- Clear thinking first
- Tools second
- Code as a means, not an end
